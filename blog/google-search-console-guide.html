홈페이지를 만들고 SEO 작업까지 마쳤다면, 그다음 질문은 "그래서 실제로 검색에 얼마나 노출되고 있는가"입니다. 이 질문에 답해주는 유일한 무료 공식 도구가 구글 서치 콘솔입니다.

구글 서치 콘솔이란

구글 서치 콘솔(Google Search Console)은 내 사이트가 구글 검색에서 어떻게 노출되고 있는지, 어떤 검색어로 유입되는지, 색인 상태는 어떤지, 오류는 없는지를 확인할 수 있는 구글의 무료 웹마스터 도구입니다.

시작하는 법

  1. search.google.com/search-console에 구글 계정으로 접속한다.
  2. 'URL 접두어' 또는 '도메인' 방식으로 속성을 추가한다.
  3. 제공되는 방법(HTML 태그, DNS 레코드 등) 중 하나로 소유권을 확인한다.
  4. 사이트맵을 제출한다.

가장 자주 보게 될 리포트 4가지

1. 실적(Performance) 리포트

어떤 검색어로, 몇 번 노출되고, 몇 번 클릭됐는지, 평균 게재순위는 어느 정도인지 보여줍니다. 노출은 많은데 클릭률이 낮은 검색어를 찾아 제목 태그와 메타 설명을 개선하는 데 활용합니다.

2. 색인 생성(Coverage / Indexing) 리포트

어떤 페이지가 색인됐고, 어떤 페이지가 제외됐는지, 그 이유는 무엇인지 알려줍니다. 중요한 페이지가 '검색되지 않음' 상태라면 원인을 확인해야 합니다.

3. 모바일 사용성 리포트

텍스트가 너무 작거나 버튼 간격이 좁은 등, 모바일에서 사용성이 떨어지는 페이지를 찾아줍니다.

4. 링크 리포트

외부에서 내 사이트로 들어오는 백링크와, 사이트 내부에서 가장 많이 링크되는 페이지를 보여줍니다.

실전 팁 — 새 페이지를 발행한 직후, '색인 생성' 상단의 URL 검사 도구에 해당 URL을 입력하고 '색인 생성 요청'을 누르면 자동 크롤링을 기다리지 않고 더 빠르게 검토를 요청할 수 있습니다.

애널리틱스와 함께 봐야 완성된다

서치 콘솔이 '검색엔진에서의 상태'를 보여준다면, 방문 이후의 행동은 구글 애널리틱스에서 확인해야 합니다. 두 데이터를 함께 봐야 "검색에서 잘 보이는데 방문 후 바로 이탈한다"거나 "노출은 적은데 들어온 사람은 오래 머문다"는 식의 진짜 개선 지점을 찾을 수 있습니다.

→ 홈페이지 구글 애널리틱스, 연동하고 제대로 활용하는 법

사이트맵 제출도 여기서

서치 콘솔은 사이트맵을 제출하고 상태를 확인하는 창구이기도 합니다. 사이트맵과 robots.txt를 아직 정리하지 않았다면 먼저 준비해두는 것이 좋습니다.

→ XML Sitemap과 robots.txt 완벽 가이드

정리하며

서치 콘솔은 처음 등록하고 나면 특별히 손댈 일이 없어 보이지만, 실적 리포트를 한 달에 한 번이라도 들여다보는 습관만으로 어떤 콘텐츠가 통하고, 어떤 페이지에 문제가 있는지 훨씬 빠르게 파악할 수 있습니다. SEO는 결국 추측이 아니라 데이터를 보는 습관에서 시작됩니다.

자주 묻는 질문

서치 콘솔과 구글 애널리틱스는 뭐가 다른가요?

서치 콘솔은 '검색엔진이 내 사이트를 어떻게 보고 있는가'(노출, 클릭, 색인, 검색어)를 보여주고, 애널리틱스는 '방문자가 사이트에 들어온 이후 무엇을 하는가'(체류시간, 이탈률, 전환)를 보여줍니다. 두 도구는 서로 다른 데이터를 다루므로 함께 사용하는 것이 좋습니다.

서치 콘솔 소유권 확인은 어떻게 하나요?

HTML 파일 업로드, HTML 태그 삽입, 도메인 이름 공급자를 통한 DNS 레코드 추가, 구글 애널리틱스 연동 등 여러 방법이 있습니다. 홈페이지 제작 플랫폼에 따라 지원하는 방식이 다르므로, 가장 간단한 방법을 플랫폼 설정에서 먼저 확인하는 것이 좋습니다.

색인 생성 요청을 매번 눌러야 하나요?

새 글을 발행할 때마다 수동으로 요청할 필요는 없습니다. 사이트맵이 정상적으로 제출돼 있다면 구글이 주기적으로 크롤링하며 자동으로 새 페이지를 발견합니다. 다만 빠른 노출이 필요한 페이지라면 URL 검사 도구로 개별 요청하는 것이 효과적입니다.

만들고 끝이 아니라 데이터로 관리하는 홈페이지,
서치 콘솔 세팅까지 함께 도와드립니다
