홈페이지 키워드 리서치 가이드, 검색어 찾기부터 페이지 배치까지

2026. 10. 28 · 이수연

홈페이지를 만들고 나서 "우리 홈페이지는 왜 검색에 안 나오지?"라고 묻는 분들께 가장 먼저 확인하는 것이 있습니다. 바로 사람들이 실제로 검색하는 단어와 홈페이지에 적힌 단어가 일치하는가입니다. 아무리 디자인이 좋고 메타 태그를 잘 써도, 고객이 쓰지 않는 단어로 페이지를 채웠다면 검색 결과에 나타날 이유가 없습니다.

이 글에서는 키워드 리서치를 처음 해보는 분도 따라 할 수 있도록, 검색 의도 이해부터 무료 도구 활용, 페이지별 배치, 발행 후 검증까지 한 흐름으로 정리했습니다. 개별 SEO 요소(제목 태그, URL, 내부 링크 등)는 이미 다른 글에서 자세히 다뤘기 때문에, 이 글은 "어떤 단어를 어떤 페이지에 쓸 것인가"를 결정하는 단계에 집중합니다.

1. 키워드 리서치란, 그리고 언제 해야 할까

키워드 리서치는 잠재 고객이 검색창에 입력하는 단어와 문장을 조사하고, 그중 우리 홈페이지가 답할 수 있는 것을 골라 페이지에 배정하는 작업입니다. 단순히 검색량이 큰 단어를 찾는 일이 아니라, 고객의 언어를 파악해 홈페이지 구조와 문구에 반영하는 과정에 가깝습니다.

가장 효과적인 시점은 홈페이지 기획 단계입니다. 페이지 구성과 메뉴 이름, URL이 키워드를 기준으로 짜이면 나중에 따로 SEO 작업을 덧붙이는 것보다 훨씬 자연스럽습니다. 제작 전이라면 홈페이지 기획서 작성 가이드의 페이지 구성 단계에서 이 글의 결과물을 함께 반영해 보세요. 이미 운영 중인 사이트라면 리뉴얼이나 신규 콘텐츠 추가 시점이 적기이며, 리뉴얼이라면 홈페이지 리뉴얼할 때 SEO 순위 떨어뜨리지 않는 법도 함께 확인하시길 권합니다.

2. 검색 의도 4가지와 페이지 유형 연결

같은 단어라도 검색하는 사람의 목적은 다릅니다. 키워드 리서치에서 검색량보다 먼저 봐야 하는 것이 검색 의도(Search Intent)입니다. 의도와 맞지 않는 페이지는 아무리 최적화해도 상위에 오르기 어렵고, 올라가도 방문자가 바로 떠납니다.

검색 의도를 확인하는 가장 빠른 방법

후보 키워드를 네이버와 구글에 직접 검색해 상위 노출된 페이지의 유형을 살펴보세요. 상위 10개가 대부분 비교 글이라면 그 키워드의 의도는 비교·조사형이고, 상위에 쇼핑몰 상품 페이지가 가득하다면 행동형입니다. 내가 만들려는 페이지 유형이 검색 결과와 다르다면 키워드를 바꾸거나 페이지 유형을 맞추는 쪽이 현실적입니다.

키워드 하나에 페이지 하나, 그리고 그 페이지는 하나의 검색 의도에 답한다 — 키워드 리서치의 가장 기본 원칙입니다.

3. 키워드 유형 이해하기

검색어 길이에 따른 구분

  • 짧은 키워드(헤드): "홈페이지 제작"처럼 한두 단어. 검색량이 크지만 의도가 다양하고 경쟁이 치열합니다.
  • 중간 키워드: "병원 홈페이지 제작"처럼 업종이나 조건이 붙은 형태. 의도가 분명해지고 경쟁이 줄어듭니다.
  • 롱테일 키워드: "강남 피부과 홈페이지 제작 비용"처럼 구체적인 문장형. 검색량은 작아도 문의·구매 가능성이 높습니다.

브랜드 키워드와 비브랜드 키워드

브랜드 키워드는 회사명·상호명이 들어간 검색어로, 이미 나를 아는 사람이 찾아옵니다. 비브랜드 키워드는 나를 모르는 사람이 문제나 필요를 검색하는 단어입니다. 신규 고객 유입은 비브랜드 키워드에서 나오기 때문에, 신생 사이트일수록 롱테일 비브랜드 키워드를 중심으로 시작하는 것이 효율적입니다.

지역 키워드

오프라인 매장이나 상담 기반 업종은 "지역명 + 서비스명" 조합이 가장 강력합니다. 지역 키워드는 검색량이 크지 않아도 방문·예약 의도가 분명하기 때문에, 업종 홈페이지에서는 반드시 별도로 조사해야 합니다.

4. 키워드 리서치 7단계

1단계. 씨앗 키워드 목록 만들기

먼저 내 사업을 설명하는 단어를 20~30개 적습니다. 서비스명, 고객이 겪는 문제, 제품 종류, 지역명, 자주 받는 문의 질문이 재료입니다. 이때 내가 쓰는 전문 용어가 아니라 고객이 쓰는 단어로 적는 것이 중요합니다. 영업·상담 과정에서 고객이 실제로 사용한 표현을 기록해 두었다면 가장 좋은 출발점이 됩니다.

2단계. 자동완성·연관검색어로 확장하기

네이버와 구글 검색창에 씨앗 키워드를 입력하면 자동완성 목록이 나타납니다. 검색 결과 하단의 연관검색어, 구글의 "다른 사람들이 함께 찾는 질문" 영역도 실제 사용자의 검색 패턴을 반영합니다. 한 번에 20~50개 후보를 모으는 데 가장 빠르고 비용이 들지 않는 방법입니다.

3단계. 네이버 검색광고 키워드 도구로 검색량 확인

네이버 검색광고 계정을 만들면 키워드 도구에서 후보 키워드의 PC·모바일 월간 검색수와 경쟁 정도, 연관 키워드를 한 번에 볼 수 있습니다. 광고를 집행하지 않아도 조회가 가능합니다. 검색량이 아주 적은 키워드는 정확한 숫자 대신 "< 10"처럼 구간으로 표시되므로, 이런 키워드는 "수요가 거의 없다"보다 "측정이 어려운 소규모 수요"로 해석하세요.

4단계. 데이터랩·구글 트렌드로 흐름 확인

네이버 데이터랩의 검색어트렌드와 구글 트렌드는 검색량의 절대값이 아니라 시기별 상대적 변화를 보여줍니다. 계절성이 있는 업종(웨딩, 여행, 입시 등)에서 콘텐츠 발행 시점을 정하거나, 두 키워드 중 어느 표현이 더 널리 쓰이는지 비교할 때 유용합니다. 예를 들어 "홈페이지 제작"과 "웹사이트 제작" 중 고객이 더 많이 쓰는 표현을 확인하는 식입니다.

5단계. 구글 키워드 플래너로 보완

구글 키워드 플래너는 구글 광고 계정이 필요하며, 광고 캠페인을 운영하지 않으면 검색량이 "1천~1만"처럼 넓은 구간으로 표시되는 경우가 많습니다. 정밀한 수치보다 아이디어 확장과 상대 비교 용도로 쓰는 것이 좋습니다. 구글 검색 비중이 높은 B2B·해외 대상 사이트라면 특히 참고할 가치가 있습니다.

6단계. 경쟁 페이지 살펴보기

후보 키워드로 직접 검색해 상위 5~10개 결과를 확인합니다. 어떤 유형의 페이지인지, 글 분량과 구성은 어떤지, 어떤 소제목을 다루는지, 빠진 정보는 없는지 살펴보세요. 대형 포털·플랫폼이 상위를 모두 차지한 키워드는 신생 홈페이지가 정면으로 이기기 어렵습니다. 반대로 상위 결과의 정보가 오래됐거나 얕다면 기회입니다.

7단계. 우선순위를 정해 페이지에 배정하기

모은 키워드를 스프레드시트에 정리하고 다음 네 가지 기준으로 판단합니다.

  • 관련성: 우리 서비스가 실제로 답할 수 있는가
  • 의도: 문의·구매로 이어질 가능성이 있는가
  • 검색량: 최소한의 수요가 확인되는가
  • 경쟁 강도: 현재 사이트 규모로 도전 가능한가

관련성이 높고 의도가 분명하며 경쟁이 낮은 키워드부터 먼저 페이지에 배정합니다. 검색량이 크지만 경쟁이 센 키워드는 롱테일 글로 기반을 쌓은 뒤 중장기 목표로 두는 것이 현실적입니다.

6. 페이지별 키워드 배치 방법

키워드를 골랐다면 다음은 배치입니다. 핵심은 한 페이지에 주력 키워드 1개, 의미가 가까운 보조 키워드 몇 개를 배정하고, 중요한 위치에 자연스럽게 녹이는 것입니다.

제목 태그·메타 설명주력 키워드를 앞쪽에, 클릭을 부르는 문장으로제목 태그와 메타 설명 가이드

본문첫 문단에 주제를 분명히, 반복보다 동의어·연관어로 확장홈페이지 카피라이팅

내부 링크 앵커연결할 페이지의 키워드를 앵커 텍스트로내부 링크 전략

키워드 카니발라이제이션 피하기

여러 페이지가 같은 키워드와 의도를 두고 경쟁하면 검색 엔진이 어느 페이지를 보여줘야 할지 판단하기 어려워집니다. 이를 키워드 카니발라이제이션이라고 부릅니다. 예방하려면 키워드 배정표를 만들어 키워드 하나에 담당 페이지 하나가 되도록 관리하세요. 이미 비슷한 페이지가 여러 개라면 하나로 합치거나, 각 페이지가 맡는 의도를 분명히 나누는 방법이 있습니다. 합치는 경우 기존 URL은 301 리다이렉트로 연결해야 합니다.

핵심 페이지와 보조 글을 묶는 구조

"홈페이지 제작 비용"처럼 큰 주제는 서비스 소개 페이지나 핵심 가이드 글(필라 콘텐츠)이 담당하고, "랜딩페이지 제작 비용", "쇼핑몰 제작 비용" 같은 세부 키워드는 별도 글이 담당한 뒤 서로 내부 링크로 묶는 방식이 효과적입니다. 이 구조는 검색 엔진에는 주제 전문성을, 방문자에게는 이어 읽을 길을 만들어 줍니다.

업종별로 홈페이지에 담아야 할 구조는 각 업종 가이드에서 다루었습니다. 의료 업종은 광고 규정 때문에 쓸 수 있는 표현에 제한이 있으니, 병원 홈페이지 제작 가이드에서 확인하세요. 지역 기반 서비스 전반은 홈페이지 SEO 최적화 가이드와 함께 보시면 좋습니다.

8. 발행 후 검증과 주기적 점검

키워드 리서치는 한 번으로 끝나지 않습니다. 가설을 세우고, 발행하고, 데이터로 확인하는 순환입니다.

  1. 색인 확인: 페이지가 검색 엔진에 등록되었는지 확인하고, 필요하면 사이트맵을 제출합니다. 사이트맵 작성법은 XML Sitemap과 robots.txt 가이드를 참고하세요.
  2. 서치 콘솔 검색어 확인: 노출수는 있는데 클릭이 적은 검색어는 제목·메타 설명을 손볼 후보입니다. 순위는 낮지만 노출이 꾸준한 검색어는 본문을 보강할 후보입니다.
  3. 예상 밖의 검색어 수집: 내가 노리지 않았는데 유입되는 검색어는 고객의 새로운 언어입니다. 새 글이나 FAQ의 재료로 활용하세요.
  4. 전환 연결 확인: 유입이 문의로 이어지는지 애널리틱스에서 확인합니다. 홈페이지 구글 애널리틱스 활용법과 홈페이지 문의 전환율 높이는 법을 함께 참고하세요.
  5. 분기별 재점검: 키워드 배정표를 분기 또는 반기마다 갱신합니다. 새 서비스가 생기거나 검색 트렌드가 달라졌다면 즉시 반영합니다.

또한 요즘은 검색 결과뿐 아니라 AI가 답변을 생성할 때 인용할 만한 페이지가 되는 것도 중요해졌습니다. 질문형 키워드를 소제목으로 쓰고 명확한 답을 먼저 제시하는 구조는 이 흐름에도 맞습니다. 자세한 내용은 GEO 마케팅 완벽 가이드에서 다루었습니다.

9. 자주 하는 실수 6가지

  1. 검색량만 보고 고르기 — 검색량이 커도 의도가 맞지 않으면 방문자는 문의하지 않습니다.
  2. 업계 용어로 키워드 정하기 — 고객이 쓰지 않는 단어는 수요가 없습니다.
  3. 메인 페이지에 모든 키워드 몰아넣기 — 한 페이지가 여러 의도에 답하려다 아무 의도에도 답하지 못합니다.
  4. 키워드 반복 삽입 — 어색한 반복은 가독성을 해치고 품질 면에서도 이점이 없습니다. 자연스러운 문장과 연관어로 풀어 쓰세요.
  5. 경쟁 분석 생략 — 상위 결과가 어떤 페이지인지 보지 않고 쓰면 의도와 맞지 않는 글을 만들기 쉽습니다.
  6. AI 생성 글로 키워드만 채우기 — 검색 최적화는 도구가 아닌 판단의 문제입니다. AI를 활용하더라도 사람이 의도와 정확성을 확인해야 하며, 이 부분은 AI로 만든 홈페이지, SEO 최적화까지 정말 될까?에서 더 자세히 다루었습니다.

10. 자주 묻는 질문

홈페이지 키워드 리서치는 유료 도구 없이도 할 수 있나요?

가능합니다. 네이버·구글 자동완성과 연관검색어, 네이버 데이터랩, 구글 트렌드, 구글 서치 콘솔은 모두 무료입니다. 네이버 검색광고 키워드 도구도 광고를 집행하지 않아도 계정 가입 후 월간 검색수를 조회할 수 있습니다. 유료 도구는 키워드 수가 많은 대형 사이트에서 작업 시간을 줄여주는 용도에 가깝습니다.

검색량이 적은 키워드도 홈페이지에 쓸 가치가 있나요?

있습니다. 검색량이 적어도 의도가 구체적인 롱테일 키워드는 경쟁이 낮고 문의나 구매로 이어질 가능성이 높은 경우가 많습니다. 특히 지역명과 서비스명이 결합된 키워드는 검색량이 작아도 전환 가치가 큽니다.

한 페이지에 키워드를 몇 개까지 넣어야 하나요?

페이지당 주력 키워드는 1개, 의미가 가까운 보조 키워드는 2~5개 정도로 잡는 것이 일반적입니다. 숫자보다 중요한 것은 한 페이지가 하나의 검색 의도에 답하도록 만드는 것이며, 키워드를 억지로 반복하기보다 자연스러운 문장 안에서 쓰는 것이 좋습니다.

키워드 리서치는 얼마나 자주 다시 해야 하나요?

새 페이지를 기획할 때마다 하고, 기존 키워드 전체는 분기 또는 반기에 한 번 점검하는 것을 권합니다. 구글 서치 콘솔의 검색어 데이터를 매달 확인하면 예상하지 못한 유입 키워드를 발견해 콘텐츠에 반영할 수 있습니다.

같은 키워드로 여러 페이지를 만들면 어떻게 되나요?

같은 사이트의 여러 페이지가 하나의 키워드와 의도를 두고 경쟁하는 키워드 카니발라이제이션이 생길 수 있습니다. 검색 엔진이 어떤 페이지를 보여줄지 판단하기 어려워 순위가 오르내리거나 약해질 수 있으므로, 페이지마다 담당 의도를 나누거나 비슷한 페이지를 하나로 합치는 것이 좋습니다.

정리하며

키워드 리서치는 복잡한 기술이 아니라 고객의 언어를 듣고, 그 언어로 홈페이지를 설계하는 일입니다. 씨앗 키워드를 모으고, 검색 의도를 확인하고, 도구로 수요를 점검한 뒤, 페이지마다 하나의 키워드와 의도를 배정하세요. 그리고 발행 후에는 서치 콘솔 데이터로 가설을 검증하며 다듬어 가면 됩니다. 이미 만든 사이트라면 키워드 배정표부터 한 장 만들어 보는 것만으로도 개선 포인트가 보이기 시작합니다.
