홈페이지 오픈 전 검수 체크리스트 40가지, 런칭 직전에 꼭 확인할 것들

2026. 10. 12 · 이수연

홈페이지 오픈 직전에 가장 많이 나오는 말은 "어? 이건 확인 안 했네요"입니다. 디자인이 끝났다고 오픈 준비가 끝난 것은 아닙니다. 이 글은 제작사와 발주자 모두가 함께 쓸 수 있도록 7개 영역, 40개 항목의 검수 기준과 런칭 당일 순서를 정리한 체크리스트입니다.

1. 검수는 누가, 언제, 어떻게 하나

검수는 개발이 끝난 뒤 한 번에 몰아서 하면 수정 범위가 커집니다. 디자인 완료 후 1차, 개발 완료 후 2차, 오픈 직전 3차로 나누어 진행하는 것을 권장합니다. 전체 일정에서 검수가 차지하는 구간은 홈페이지 제작 기간 가이드에서 확인할 수 있습니다.

차수시점중점
1차디자인 확정 후시안 대비 구현, 문구·이미지 오탈자
2차개발 완료 후기능, 폼, 링크, 반응형, 브라우저 호환
3차오픈 직전SEO, 보안, 법적 고지, 분석 도구

검수 결과는 말로 전달하지 말고 스프레드시트로 정리하세요. '페이지 / 문제 내용 / 캡처 / 우선순위 / 처리 상태' 5개 열이면 충분합니다. 수정 요청이 누락되는 일을 크게 줄여 줍니다.

2. 디자인·콘텐츠 검수 (8개)

  1. 시안과 실제 화면의 여백·정렬·폰트 크기가 일치하는가
  2. 모든 페이지에서 로고, 메뉴, 푸터가 동일하게 보이는가
  3. 더미 텍스트(Lorem ipsum, "텍스트를 입력하세요")가 남아 있지 않은가
  4. 오탈자·띄어쓰기·고유명사 표기(회사명, 상품명)가 맞는가
  5. 이미지가 깨지거나 늘어나 보이지 않는가
  6. 이미지 대체 텍스트(alt)가 중요한 이미지에 입력되어 있는가
  7. 대표 이미지, 사진의 사용 권한을 확보했는가
  8. 연락처·주소·사업자 정보가 정확한가

문구 품질은 홈페이지 카피라이팅 가이드, 폰트와 색상 일관성은 폰트 가이드와 컬러 가이드를 기준으로 점검하세요.

3. 기능 검수 (8개)

  1. 모든 메뉴·버튼·내부 링크가 올바른 페이지로 연결되는가
  2. 외부 링크는 새 창으로 열리고 정상 작동하는가
  3. 문의 폼을 직접 제출했을 때 담당자 메일/알림이 실제로 도착하는가
  4. 필수 입력 누락, 잘못된 이메일 입력 시 안내 문구가 나오는가
  5. 전화번호·이메일 링크(tel:, mailto:)가 작동하는가
  6. 팝업·슬라이더가 닫히고 넘어가는가
  7. 게시판·갤러리 등록, 수정, 삭제가 정상인가
  8. 결제·예약 기능이 있다면 테스트 결제와 취소까지 확인했는가

가장 자주 놓치는 항목. 문의 폼입니다. 화면에서 "접수되었습니다"가 떠도 메일이 스팸함에 들어가거나 발송 설정이 비어 있는 경우가 많습니다. 오픈 전 반드시 실제 수신 여부를 확인하세요.

4. 모바일·호환성 검수 (6개)

  1. 스마트폰 가로·세로 모두에서 레이아웃이 깨지지 않는가
  2. 버튼·링크가 손가락으로 누르기 충분한 크기인가
  3. 가로 스크롤이 생기지 않는가
  4. Chrome, Safari, Edge, 삼성 인터넷에서 모두 정상인가
  5. 아이폰 Safari에서 폰트·고정 요소가 정상인가
  6. 입력창 선택 시 화면이 의도치 않게 확대되지 않는가

화면 크기별 설계 기준은 반응형 웹디자인 가이드, 모바일 사용성은 모바일 최적화 가이드를 참고하세요.

5. SEO·분석 검수 (7개)

  1. 페이지마다 고유한 title과 meta description이 있는가
  2. H1이 페이지당 하나이고 제목 구조가 논리적인가
  3. canonical 주소와 대표 도메인(https, www 여부)이 통일되어 있는가
  4. robots.txt와 noindex가 오픈 후에도 차단 상태가 아닌가
  5. sitemap.xml이 생성되어 있고 접근 가능한가
  6. OG 이미지와 파비콘이 설정되어 있는가
  7. 구글 애널리틱스 등 분석 도구가 작동하는가

테스트 기간에 걸어둔 검색 차단 설정을 풀지 않는 사고는 생각보다 흔합니다. 세부 기준은 sitemap·robots.txt 가이드, 타이틀·메타 디스크립션 가이드, 파비콘·OG 이미지 가이드에서 확인하세요. 오픈 후에는 구글 서치콘솔과 네이버 서치어드바이저 등록까지 마치면 완성입니다. 분석 설정은 구글 애널리틱스 가이드를 따르세요.

6. 속도·보안 검수 (6개)

  1. HTTPS가 적용되고 http 접속 시 https로 이동하는가
  2. 혼합 콘텐츠(https 페이지 안의 http 자원) 경고가 없는가
  3. 이미지가 최적화되어 첫 화면이 빠르게 뜨는가
  4. 관리자 로그인 주소·초기 비밀번호가 변경되었는가
  5. 불필요한 테스트 계정·테스트 페이지가 삭제되었는가
  6. 백업이 설정되어 있는가

세부 방법은 로딩 속도 가이드, 이미지 최적화 가이드, 보안 가이드에서 다뤘고, 호스팅·인증서 설정은 호스팅·SSL·CDN 가이드에서 정리했습니다.

7. 법적 고지·계약 검수 (5개)

  1. 개인정보처리방침이 게시되고 푸터에서 접근 가능한가
  2. 문의 폼에 개인정보 수집·이용 동의 절차가 있는가
  3. 이용약관(필요 시)과 사업자 정보 표기가 있는가
  4. 사용한 폰트·이미지·아이콘의 라이선스를 확인했는가
  5. 소스 파일·계정 권한·저작권 귀속이 계약서대로 인계되는가

고지 문서는 개인정보처리방침·이용약관 가이드, 인계 항목은 제작 계약서·저작권 가이드를 확인하세요. 접근성은 웹 접근성 가이드에 따라 추가 점검할 수 있습니다.

8. 런칭 당일 순서와 오픈 후 48시간

순서할 일
오픈 전날최종 백업, 3차 검수 완료, 수정 동결(Freeze)
오픈 당일 1도메인 연결·DNS 반영 확인, HTTPS 확인
오픈 당일 2검색 차단(noindex, robots) 해제 확인
오픈 당일 3문의 폼 실제 제출 테스트, 분석 도구 실시간 확인
오픈 당일 4서치콘솔·서치어드바이저 등록, 사이트맵 제출
오픈 후 48시간404 오류, 폼 수신, 모바일 접속 이상 여부 재점검

기존 사이트를 교체하는 경우에는 주소 변경 처리가 핵심입니다. 리뉴얼 SEO 순위 유지법과 404·301 리다이렉트 가이드를 반드시 함께 보세요.

자주 묻는 질문 (FAQ)

Q. 검수는 몇 번 정도 하는 것이 적당한가요?

디자인 후, 개발 후, 오픈 직전의 3차 검수를 권장합니다. 단계별로 점검 대상이 달라서 한 번에 몰아서 하는 것보다 수정 비용과 일정 지연이 줄어듭니다.

Q. 검수 중 수정 요청은 제작사에 어떻게 전달해야 하나요?

페이지 주소, 문제 내용, 캡처, 우선순위를 스프레드시트로 정리해 한 번에 전달하는 것이 좋습니다. 메신저로 흩어서 전달하면 누락과 중복이 생기기 쉽습니다.

Q. 오픈 후 발견한 오류는 무료로 수정받을 수 있나요?

계약서의 하자보수 기간과 범위에 따라 다릅니다. 보통 오픈 후 일정 기간의 오류 수정은 포함되지만, 기능 추가나 디자인 변경은 별도 비용인 경우가 많습니다. 계약 단계에서 문서로 확인하세요.

Q. 모든 브라우저와 기기를 다 테스트해야 하나요?

모든 조합을 테스트하기는 어렵습니다. 방문자 비중이 높은 Chrome, Safari, Edge와 안드로이드·아이폰 실기기 위주로 점검하고, 분석 도구의 접속 환경 통계가 쌓이면 우선순위를 조정하세요.

마무리

검수 체크리스트의 목적은 완벽한 사이트가 아니라 치명적인 실수를 오픈 전에 걸러내는 것입니다. 문의 폼 수신, 검색 차단 해제, HTTPS, 법적 고지, 이 네 가지만큼은 반드시 직접 확인하세요. 오픈 이후의 관리는 홈페이지 유지보수 가이드로 이어서 준비하면 좋습니다.
