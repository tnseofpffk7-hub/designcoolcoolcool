제목 태그와 메타 설명,
클릭을 부르는 두 줄 쓰는 법

2026. 09. 23 · 이수연

검색 결과에서 방문자가 가장 먼저, 그리고 가장 짧은 시간 동안 읽는 텍스트가 제목 태그와 메타 설명입니다. 순위가 아무리 높아도 이 두 줄이 클릭을 부르지 못하면 방문으로 이어지지 않습니다.

제목 태그(Title Tag), 페이지의 첫인상

제목 태그는 <title> 태그 안의 텍스트로, 브라우저 탭과 검색 결과 상단 링크에 그대로 노출됩니다. 구글은 보통 공백 포함 약 50~60자, 픽셀 기준으로는 대략 600px 안팎까지만 잘리지 않고 표시합니다. 그 이상은 검색 결과에서 말줄임(...) 처리됩니다.

제목 태그 작성 원칙

  • 핵심 키워드는 앞쪽에 배치한다 — 뒤로 갈수록 잘릴 위험이 커집니다.
  • 페이지마다 고유한 제목을 쓴다 — 같은 제목을 여러 페이지에 재사용하면 검색엔진이 어떤 페이지를 우선해야 할지 혼란스러워합니다.
  • 클릭베이트보다 정확한 예고에 가깝게 쓴다 — 기대와 실제 콘텐츠가 다르면 이탈률만 올라갑니다.

메타 설명(Meta Description), 클릭을 결정짓는 두 번째 문장

메타 설명은 순위에 직접적인 영향을 주는 요소는 아니지만, 검색 결과에서 제목 아래 노출되는 요약문으로 클릭 여부를 결정하는 핵심 문구입니다. 보통 120자 내외까지 안정적으로 노출되며, 그 이상은 잘릴 수 있습니다.

메타 설명 작성 원칙

  • 페이지 내용을 정확히 요약하되, 방문자가 얻을 수 있는 것을 한 문장으로 담는다.
  • 검색한 키워드와 겹치는 단어가 포함되면 구글이 해당 부분을 볼드 처리해 시선을 끈다.
  • 모든 페이지에 동일한 문구를 복사해 붙이지 않는다.

페이지 타입별 예시

페이지 타입제목 태그 예시
홈페이지디자인 쿨쿨쿨 — 브랜드 홈페이지 제작 스튜디오
서비스 소개홈페이지 제작 서비스 안내 | 디자인 쿨쿨쿨
블로그 글홈페이지 SEO 최적화, 처음부터 제대로 하는 방법
지역 기반 업체강남 필라테스 스튜디오 — 체험 수업 예약
참고 — 구글은 작성한 제목 태그가 검색 의도와 맞지 않다고 판단하면 자체적으로 다시 작성해 노출하기도 합니다. 이를 줄이려면 제목이 실제 페이지 내용과 정확히 일치해야 합니다.

카피라이팅과 함께 다듬기

제목 태그와 메타 설명도 결국 방문자를 설득하는 카피입니다. 홈페이지 전체의 카피라이팅 원칙을 함께 참고하면 더 완성도 높은 문구를 쓸 수 있습니다.

→ 홈페이지 카피라이팅, 클릭을 부르는 문장 쓰는 법

클릭률은 서치 콘솔에서 확인한다

제목과 메타 설명을 수정한 뒤에는 실제로 클릭률이 개선됐는지 데이터로 확인하는 과정이 필요합니다.

→ 구글 서치 콘솔, 가입부터 실전 활용까지

정리하며

제목 태그와 메타 설명은 짧지만, 방문자가 수십 개의 검색 결과 중 내 페이지를 선택하게 만드는 유일한 순간입니다. 페이지를 새로 만들 때마다 복사-붙여넣기 대신, 그 페이지만의 고유한 한 줄을 써야 하는 이유입니다.

자주 묻는 질문

제목 태그에 브랜드명을 꼭 넣어야 하나요?

필수는 아니지만 넣는 것을 권장합니다. 글자 수 여유가 있다면 '핵심 키워드 | 브랜드명' 형태로 끝에 붙여, 브랜드 인지도와 검색 노출을 동시에 챙기는 것이 일반적입니다.

메타 설명을 안 써도 구글이 알아서 채워주지 않나요?

메타 설명을 비워두면 구글이 본문 일부를 임의로 발췌해 보여주는데, 이 발췌문은 페이지의 핵심 가치를 담지 못하는 경우가 많습니다. 클릭률을 관리하려면 메타 설명을 직접 작성하는 것이 안전합니다.

제목 태그와 메타 설명은 얼마나 자주 수정해야 하나요?

정해진 주기는 없지만, 서치 콘솔에서 노출 대비 클릭률이 낮은 페이지를 발견했다면 우선적으로 손보는 것이 효율적입니다. 클릭률이 낮다는 것은 검색엔진이 보여주는 노출 결과가 방문자의 기대를 채우지 못하고 있다는 신호입니다.
